# 离线瓦片放这里

程序会**优先**从 `web/tiles/{z}/{x}/{y}.png` 读底图；读不到才去连在线 OSM；
两边都不通时，地图自动降级成"相对位置点阵"，并提示底图不可用。

## 怎么把瓦片放进来

任选一种：

1. **MOBAC（Mobile Atlas Creator）** —— 框选县城范围 + 缩放级别（建议 z13–z17），
   导出 `osmdroid SQLite` 或 `MBTiles`，再用脚本切成 `z/x/y.png` 目录结构。
2. **OsmAnd / Organic Maps 的离线包** —— 下载对应区域后导出瓦片。
3. **自己搭一次切片服务** —— 用 `tilemaker` + `mapnik` 从 `planet.osm.pbf` 切，
   县城范围通常只有几十到两百 MB。

> 提示：中国网络环境下 `tile.openstreetmap.org` 经常连不上（实测 8 秒超时），
> 所以**离线瓦片不是优化项，是必需品**。

## 目录示意

```
web/tiles/
├── 15/
│   ├── 26972/
│   │   ├── 13461.png
│   │   └── 13462.png
│   └── 26973/
└── 16/
```

放好之后刷新页面即可，不需要改任何代码。
