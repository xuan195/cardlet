# 云开发：数据上传的技术方案

解决"**商家怎么把数据传出去**"——不买服务器、不备案域名、商家不用注册账号。

## 一句话原理

> 云存储放**文件**，云数据库放**指针**，云函数做**校验和聚合**。
> 微信的"仅创建者可写"规则替我们完成了无审批的权限隔离。

## 三个文件

| 文件 | 作用 |
|---|---|
| `publishShop.js` | 云函数：校验字段 → 写 `catalog/<id>.json` → upsert 索引记录 |
| `getIndex.js` | 云函数：合并索引，返回全城店铺列表（支持 `since` 增量） |
| `devcloud.py` | 本地模拟器，`python cloud/devcloud.py` 跑 17 项端到端自测 |

## 数据怎么分

```
云存储  catalog/<店铺id>.json     完整目录，公开可读，只有属主能覆盖
云数据库 shops/<店铺id>           索引：店名/坐标/营业状态/摘要/哈希/fileID
```

数据库里**没有任何业务内容**，只有指针。想搬家，把 `catalog/` 整包导走即可。

## 部署步骤

1. 小程序后台开通云开发，拿到环境 ID
2. 建集合 `shops`，权限选 **"所有用户可读，仅创建者可写"**
   （自定义安全规则：`{"read": true, "write": "doc._openid == auth.openid"}`）
3. 云存储权限：**"所有用户可读，仅创建者可写"**
4. 开发者工具里右键两个云函数 → 上传并部署
5. 小程序端调用：

```js
// 上传
wx.cloud.callFunction({
  name: 'publishShop',
  data: { shop: { id: 'haoyouduo', name: '好又多超市', open: true, items: [...] } }
})

// 拉索引
wx.cloud.callFunction({ name: 'getIndex', data: { since: lastSyncTime } })
```

## 三条红线在代码里的落地

`publishShop.js` 里有一个 `FORBIDDEN` 列表，出现 `price / rating / review / order / pay`
等字段名直接拒绝整个请求，不做"尽力而为"的清洗：

```js
const FORBIDDEN = ['price', 'amount', 'money', 'fee', 'rate', 'score',
                   'rating', 'review', 'comment', 'star', 'order', 'pay']
```

这不是防君子，是防**未来的自己**——某天想加一个"参考价"功能时，这行代码会拦住。

## 这条路放弃了什么

| 放弃 | 换来 |
|---|---|
| 数据完全不出门 | 远程可见、不用运维、不用备案 |
| 零成本 | 约 120 元/年 |
| 完全自主 | 可随时整包导出搬到别处 |

**兜底仍然保留**：同一 WiFi 下优先走局域网直连（`server.py`），
云挂了、没网了、额度用完了，店里照样能看货。
