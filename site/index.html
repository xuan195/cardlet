名片只递给你
认识的人，不给平台。

每台手机就是一个完整钱包。名片靠面对面扫码递过去， 同一个 WiFi 下自动比对版本、补齐过期的 —— 全程没有服务器。 不是因为省钱，而是因为没有服务器，才不需要把名片交给谁保管。

三条红线

没有这三个字段，
就没有变坏的权力位。

一个工具要变成平台，需要三个支点：把价格拿来比、把口碑变成评分、把钱经一手。 这三样在这里都不是"约定不做"，而是数据结构里根本没有。

01

不标价格

没有价格数据可卖，就没有比价、竞价排名和价格战。名片上写"我提供什么"，不写多少钱。

02

不做评价

没有评分体系，就没有刷单、没有差评师勒索、没有人能靠限流收你的钱。

03

不承载交易

钱不经过工具，就没有佣金、没有资金沉淀，也不构成"平台经营者"。

所以屠龙少年变恶龙需要的那个位置，压根不存在。

边界

你没扫过的名片，
永远不会出现在你手机里。

这不是一条产品策略，是钱包这个东西本身的规矩 —— 你钱包里有谁的卡片， 只取决于谁把卡片递给了你。

不是 平台目录
没有全城搜索，没有黄页式收录。名片只能从一个人手里，递到另一个人手里。
不是 点评网站
没有星级、没有评价、没有"附近评分最高"。只有店主自己写的"我提供什么"。
不是 抽成中介
不碰钱，不做担保，不留手续费的口子。生意谈成了，那是你和对方的事。
怎么用

递名片这件事，
本来就不该经过中间人。

第一步

做一张自己的

姓名和店名填一个就成立。一个人可以有好几张 —— 店一张、跑腿一张、临时帮工一张。

第二步

让对方扫

二维码里只有名片数据，不含任何服务器地址。换台手机、换个网络，码照样有效。

第三步

见面再扫一次

你改完内容，版本号 +1。对方再扫到同一张时只刷新这一张，不会多出陌生人来。

同步

没有服务器，
靠三条物理通道同步。

两台手机之间的数据只能通过这几条路过去。这不是技术选型，是物理限制 —— 没有共享网络，就没有通道。

二维码

一方屏幕、一方摄像头。码里只有名片数据，扫完直接进钱包。

主力 · 只要一方配合

同一个 WiFi

两台手机连同一个路由器、都开着应用，自动发现并只交换双方都持有的名片。

自动 · 需双方都开着

转发一张图片

把二维码截图发到微信，收到的人扫一下就收进手机。零基础设施的"广播"。

最实用 · 不需要见面

自动同步默认是关的 —— 它要求两台手机连同一个 WiFi 且都开着应用， 一直开着只会白耗电。想刷新某个人的名片，还是见面扫一下最省事。

下载 cardlet.apk
一 · 下载 点上面的按钮，APK 会存到手机的"下载"目录。
二 · 允许安装 首次安装时系统会拦一下，在弹窗里允许"安装未知来源应用"。
三 · 填一张试试 打开「名片」，在"我的名片"里新建一张，填个名字就能生成二维码。

关于这个安装包：它当前是调试签名的开发版本，用来验证功能，不是应用商店的正式版。 安装包体积小是因为它是 WebView 壳，界面在本机渲染，不需要打包整套框架。

不想装也可以先在浏览器里试用。 网页版预置了四张示例名片，名片夹、编辑、二维码都能用； 地图底图和自动同步需要服务端配合，网页版里会降级或不生效 —— 完整效果还是装在手机上。

开源

源码在 GitHub，MIT 许可。

服务端是纯 Python 标准库，一行依赖都不用装；界面是一个 HTML 加几个 JS 文件。 引擎还有一份 Python 参考实现，和 JS 版本双向互验签名 —— 两边算出来的结果必须一致。
